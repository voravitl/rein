# ตั้งค่า provider ของ Crux

ไฟล์ชุดนี้ปิดการเรียกโมเดลไว้เป็นค่าเริ่มต้น และยังไม่ระบุ model หรือ probe สร้างสำเนาสำหรับโปรเจกต์ด้วย `rein config init --dir <new-directory>` แล้วตั้งค่าจากข้อมูลที่ตรวจได้จริงก่อนเปิดใช้งาน

ตรวจสถานะเป็นภาษาไทยได้ด้วย:

```sh
rein config check --dir plugins/crux/config --quota orca --format text
```

คำสั่งนี้อ่านข้อมูลจาก Orca โดยไม่เรียกโมเดล โควตาที่เห็นยังไม่ยืนยันว่า worker ใช้บัญชีเดียวกัน และข้อมูล OpenCode Go ใช้แทนโควตารุ่นฟรีของ OpenCode2 ไม่ได้ ค่าไม่ทราบต้องคงเป็นไม่ทราบ

ถ้าต้องการอ่านโควตา Codex โดยตรงโดยไม่ผ่าน Orca ใช้:

```sh
rein config check --dir plugins/crux/config --quota native --format text
```

ทางนี้อ่าน native Codex app-server โดยไม่ส่งคำถามให้โมเดล และไม่เรียก CLI ของอีกสาม harness ข้อดีคืออ่านข้อมูลแยกจาก cache ของ Orca ได้ ข้อจำกัดคือรองรับเฉพาะ Codex และยังไม่ผูกบัญชีกับ worker ผลนี้ไม่รีเฟรช Orca ไม่แทนการตรวจโควตาก่อนส่งงาน และไม่เปิดสิทธิ์เรียกโมเดล ชื่อช่วงและเวลาที่คืนมาคงตาม API; เวลาอ่านไม่รับรองความสดของข้อมูลต้นทาง

| ไฟล์ | ใช้กำหนดอะไร |
| --- | --- |
| `fallback-chain.json` | provider, model, คำสั่งตรวจโมเดล และลำดับคนทำงานกับคนตรวจ |
| `profile.json` | งบและนโยบายของเจ้าของงาน |

ระบุ `--config <directory>/fallback-chain.json` ตอนเลือกเส้นทาง และ `REIN_PROFILE=<directory>/profile.json` สำหรับนโยบายงบ ต้องมี model ID ที่ตรวจแล้ว ขอบเขต probe เพดานที่เป็นค่าบวก และสายตรวจงานที่แยกจากผู้เขียนก่อนเปิดเรียกโมเดล งบทั่วไปที่ไม่ระบุหรือเป็นศูนย์ไม่ได้ห้ามใช้เงิน ส่วน calibration ต้องมีสิทธิ์และเพดานเฉพาะของมัน

ค่าเริ่มต้นเปิด `require_orca_quota: true` ต้องตั้ง `quota_windows` ให้ตรงกับกลุ่มโควตาของโมเดลจริง และอาจกำหนด `quota_reserve_percent` เพิ่มได้ ข้อมูลทุกช่วงที่เลือกต้องสด ทราบยอดคงเหลือ และเหลือมากกว่าส่วนสำรอง ระบบตรวจซ้ำก่อนเปิด worker ส่วน Claude/Codex ตรวจช่วงโควตาร่วมที่สังเกตได้เพิ่มเติมด้วย

แนะนำคงการตรวจโควตาไว้ ข้อดีคือหยุดก่อนเรียกเมื่อข้อมูลเก่าหรือยอดไม่พอ ข้อจำกัดคืออาจส่งงานไม่ได้เมื่อ Orca ไม่มีข้อมูล ต้องรีเฟรชผ่านช่องทางที่รองรับ การผ่านขั้นนี้ไม่ใช่สิทธิ์ใช้เงินหรือหลักฐานบัญชีของ worker ดูขอบเขตที่ยืนยันแล้วใน [readiness](../references/readiness.md)
