# การสื่อสารของ Crux

อ่านและใช้ skill [thai-communication](../skills/thai-communication/SKILL.md) กับข้อความถึงผู้ใช้ทุกชนิด ทั้งคำตอบ ความคืบหน้า คำถาม แผน รีวิว และสรุปส่งมอบ

Skill นี้เป็นกติกากลางเรื่องภาษาไทยที่เป็นธรรมชาติ กระชับ การถามให้ชัด การเลือกตารางหรือแผนภาพ และการสรุปทางไปต่อพร้อมเหตุผล ข้อดี ข้อเสีย และหลักฐาน ทุก adapter และ agent ใช้ชุดเดียวกัน เก็บคำสั่ง/error ต้นฉบับและระดับความมั่นใจของหลักฐานไว้ตามเดิม

การส่ง brief ให้ระบุเส้นทาง skill นี้ด้วย ส่วนผลลัพธ์ที่ระบบต้องอ่านให้คง schema เดิม กติกาภาษาไม่เพิ่มสิทธิ์ เปลี่ยน receipt หรือข้าม approval
